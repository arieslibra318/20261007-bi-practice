## 遊戲介紹
本作品為一款充滿 1980 年代紅白機情懷的 **8-Bit 像素風棒球 QTE 節奏打擊網頁遊戲**。
玩家扮演在第 9 局下半登場的關鍵打者，需抓準球路時機揮棒，啟動逆轉勝的史詩動畫！

- **關卡一**：3 : 2 逆轉清壘長打過場
- **關卡二**：4 : 3 關鍵追平二壘安打過場
- **關卡三**：7 : 5 再見滿貫全壘打（Walk-off Grand Slam）
